# Куда едем? — автобусы Aachen

Дом — Schanz (Jakobstraße), работа — Bushof или Kaiserplatz. Ближайшие прямые автобусы туда и обратно, с опозданиями в реальном времени.

- Адрес: https://andrii-bus.github.io/
- Данные: [Transitous](https://transitous.org/) (DELFI / AVV), без ключей и регистрации.
- Один файл `index.html`, без сборки. Остановки — в `STOPS`, «дом» — `HOME`, варианты «работы» — `WORKS`.
- `.github/workflows/bus-check.yml` после каждого изменения открывает сайт в Chrome и печатает, что видно на экране.
